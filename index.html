AirMouse

Una nueva forma de interactuar con tus dispositivos. Controlá el cursor mediante movimientos naturales utilizando tecnología inercial y comunicación inalámbrica.

Descargar software Conocer el proyecto

Tecnología que se adapta a vos.

AirMouse combina sensores inerciales, sistemas embebidos y comunicación Bluetooth para crear una forma alternativa de interacción.

¿Por qué AirMouse?

Precisión

Detección de movimientos mediante sensores inerciales.

Inalámbrico

Comunicación Bluetooth sin necesidad de cables.

Personalizable

Configuraciones adaptables a diferentes usuarios y preferencias.

Accesibilidad

Una alternativa de interacción con baja exigencia motriz.
