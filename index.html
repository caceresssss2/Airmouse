¿Qué es AirMouse?

Tecnología pensada para crear una forma alternativa, intuitiva y personalizable de controlar dispositivos.

AirMouse es un ratón aéreo inalámbrico basado en sistemas embebidos e interfaces inerciales. Utiliza un sensor MPU6050 para detectar los movimientos de la mano y un microcontrolador ESP32 para procesar y transmitir las acciones mediante Bluetooth.

Diseñado para adaptarse

AirMouse busca reducir la exigencia física y ofrecer configuraciones adaptables a diferentes usuarios.

🎯

Precisión

Detecta los movimientos mediante una unidad de medición inercial.

🔵

Inalámbrico

Comunicación Bluetooth para interactuar sin cables.

Del movimiento de tu mano al control de tu dispositivo.

Movimiento

2

MPU6050

3

ESP32

Procesa la información recibida.

4

Bluetooth

Envía las acciones al dispositivo.

AirMouse

Una nueva forma de interactuar con tus dispositivos. Controlá el cursor mediante movimientos naturales utilizando tecnología inercial y comunicación inalámbrica.

¿Qué es AirMouse?

AirMouse convierte el movimiento de tu mano en el control de tu dispositivo. Un sensor MPU6050 montado sobre el dedo índice detecta cada gesto, un ESP32 lo procesa aplicando filtros de zona muerta para evitar falsos movimientos, y todo se transmite por Bluetooth BLE como dispositivo HID: no hace falta instalar ningún programa para empezar a usarlo.
