El Proyecto

AirMouse es un ratón aéreo inalámbrico basado en sistemas embebidos e interfaces inerciales.

¿Qué buscamos?

El objetivo de AirMouse es desarrollar una alternativa intuitiva y personalizable para controlar dispositivos mediante movimientos naturales de la mano.

Accesibilidad

El proyecto está pensado especialmente para ofrecer una alternativa de interacción con baja exigencia motriz, buscando que pueda adaptarse a diferentes necesidades y preferencias.

Tecnología

AirMouse utiliza un sensor MPU6050 para detectar el movimiento y un ESP32 para procesar la información y comunicarse de forma inalámbrica.
